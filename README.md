### 🎨 Color Palette

```css
:root {
  /* ── Backgrounds ── */
  --color-bg-base:        #ffffff;   /* ██ Pure White             */
  --color-bg-light:       #f8f8f8;   /* ██ Off-White Section      */
  --color-bg-footer:      #1a1a1a;   /* ██ Dark Footer            */

  /* ── Brand Orange ── */
  --color-orange-primary: #FF6B00;   /* ██ Primary Brand Orange   */
  --color-orange-light:   #FF8C33;   /* ██ Light Orange Hover     */
  --color-orange-pale:    #FFF3E8;   /* ██ Pale Orange BG Tint    */
  --color-orange-hero:    #E85D00;   /* ██ Deep Hero Orange       */

  /* ── Text ── */
  --color-text-primary:   #1a1a1a;   /* ██ Near Black             */
  --color-text-muted:     #888888;   /* ██ Muted Gray             */
  --color-text-orange:    #FF6B00;   /* ██ Orange Accent Text     */
  --color-text-price:     #FF4500;   /* ██ Price Tag Red-Orange   */
}
```

<br/>

### 🔤 Typography

| Role | Font | Weight | Use Case |
|------|------|--------|----------|
| Hero Display | `Bangers` | 400 | Manga-style hero title |
| Section Headings | `Oswald` | 700 | "TRENDING MANGA SERIES" etc. |
| Product Names | `DM Sans` | 500 | Product card titles |
| Body / Description | `Inter` | 400 | Paragraphs, descriptions |
| Prices / Labels | `Barlow` | 600 | Price tags, badges |

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/arnavasif/manga-mint.git
cd manga-mint

# 2. Install Shopify CLI
npm install -g @shopify/cli @shopify/theme

# 3. Connect to your store
shopify auth login --store=your-store.myshopify.com

# 4. Run locally
shopify theme dev --store=your-store.myshopify.com

# 5. Push live
shopify theme push
```
